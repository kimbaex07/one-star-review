A deadpan one-star review of sleep — the everyday essential that shows
up late, leaves early, and ends its free trial the second you get
comfortable. An entry for the make.fun bounty
[One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

Why sleep: it is the essential nobody can return, refund, or escalate
to a manager — the complaint has to be filed in earnest against a thing
that cannot be fixed, and the sharpest true grievance is the timing:
sleep is worst exactly when you need it most, and best only when the
alarm is about to go off.

## Run it

```sh
python3 main.py
```

This writes the one-line review to `entry.txt` (and to
`/output/entry.txt` when the grading sandbox provides `/output`).
